대국 종료

GitHub 무료 홈페이지(Pages) 배포 가이드

이 오목 게임은 별도의 서버 설치 없이 단 하나의 index.html 파일과 WebRTC(PeerJS) 기술로 동작하므로 GitHub Pages에 무료로 올릴 수 있습니다!

  1. GitHub 저장소(Repository) 생성:
    GitHub 로그인 후 우측 상단 + → New repository를 클릭합니다. 저장소 이름(예: gomoku)을 적고 Public으로 생성합니다.
  2. index.html 파일 업로드:
    생성된 저장소 화면에서 uploading an existing file 링크를 누르고, 현재 이 코드가 저장된 index.html 파일을 드래그 앤 드롭한 뒤 하단 초록색 Commit changes 버튼을 클릭합니다.
  3. GitHub Pages 활성화:
    저장소 상단 메뉴의 Settings → 좌측 메뉴 Pages로 이동합니다. Branch 항목에서 None을 main(또는 master)으로 바꾸고 Save를 누릅니다.
  4. 친구와 접속해 대국하기:
    약 1분 뒤 https://내아이디.github.io/gomoku/ 주소가 활성화됩니다. 내가 방 만들기에서 초대링크 복사를 눌러 카카오톡/디스코드로 친구에게 보내면 바로 온라인 대국이 시작됩니다!
