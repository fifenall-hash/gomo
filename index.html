새 대국방 만들기

GitHub 무료 홈페이지(Pages) 배포 가이드

이 오목 웹앱은 별도의 백엔드 서버 구축 없이 단 하나의 index.html 파일과 공개 WebSocket 로비 브로커 + WebRTC(PeerJS) 기술로 동작하므로 GitHub Pages에 무료로 올릴 수 있습니다!

  1. GitHub 저장소(Repository) 생성:
    GitHub 로그인 후 우측 상단 + → New repository를 클릭합니다. 저장소 이름(예: gomoku)을 적고 Public으로 생성합니다.
  2. index.html 파일 업로드:
    생성된 저장소에서 uploading an existing file을 누르고, 이 코드가 담긴 index.html 파일을 업로드한 뒤 Commit changes를 클릭합니다.
  3. GitHub Pages 활성화:
    저장소 상단 Settings → 좌측 Pages 메뉴에서 Branch를 main으로 선택하고 Save를 누릅니다.
  4. 대기실에서 방 만들고 바로 대국하기:
    약 1분 뒤 생성된 홈페이지 주소로 접속하면 실시간 대기실이 나타납니다. 한 사람이 방을 만들면 접속한 다른 사람들의 대기실 목록에 즉시 방이 표시되어 클릭 한 번으로 입장할 수 있습니다!
